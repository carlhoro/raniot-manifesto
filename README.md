# Raniot Manifesto

Sitio web construido con Next.js.

## Desarrollo local

1. Instala dependencias:

```bash
npm ci
```

2. Copia variables locales:

```bash
cp .env.example .env.local
```

3. Ejecuta en modo desarrollo:

```bash
npm run dev
```

La guia de despliegue productivo se mantiene en documentacion privada local y no se publica en este repositorio.
